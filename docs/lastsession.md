# Last Sessions

| Datum | Zusammenfassung |
|-------|-----------------|
| 2026-05-16 | Projektstart umgesetzt: Es wurde ein statischer Vanilla-JS-Viewer mit Hash-Routing, Tour-JSON-Loader, Schema-Validierung, responsive UI und Demo-Tour angelegt. Tests nutzen zunächst Node's eingebauten Test-Runner, damit keine neue Dependency nötig ist. Pannellum ist weiter als spätere echte 360°-Renderer-Integration vorgesehen; die aktuelle CSS-Panorama-Darstellung ist bewusst als austauschbarer Startpunkt gekapselt. |
| 2026-05-16 | Der Viewer wurde von CSS-Panning auf einen WebGL-basierten equirectangularen 360°-Renderer umgestellt, damit hochgeladene Insta360-Panoramen in alle Richtungen inklusive oben und unten betrachtet werden können. Zusätzlich wurde ein browser-lokaler Upload- und Verbindungsflow ergänzt: mehrere Bilder werden als lokale Szenen geladen und über Hotspots an der aktuellen Blickrichtung miteinander verbunden. Automatisches Rohbild-Stitching bleibt bewusst out of scope; erwartet werden bereits gestitchte 2:1-Panoramen. |
| 2026-05-16 | Als nächsten MVP-Schritt wurde ein Tour-JSON-Download ergänzt. Die App kann jetzt den aktuell geladenen oder lokal hochgeladenen Tour-Entwurf als schemakompatible JSON-Datei speichern; lokale Object-URLs werden dabei bewusst nicht exportiert, sodass die Bilddateien neben der JSON-Datei abgelegt werden müssen. Zusätzlich wurden Export-Unit-Tests und die Architektur-/Feature-Dokumentation aktualisiert. |
